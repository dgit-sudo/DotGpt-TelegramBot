Problem: Bot won't start
Fix:     Check BOT_TOKEN is exactly copied from @BotFather (no spaces)

Problem: Can't access /admin
Fix:     Check ADMIN_IDS = YOUR_TELEGRAM_ID in .env (get ID from @userinfobot)

Problem: Database error
Fix:     Delete dotgpt_bot.db and run: python init_sample_data.py

Problem: Need to restart bot
Fix:     Go to Railway dashboard, click "More" → "Restart"

Problem: Lost bot token
Fix:     Get new token from @BotFather, update BOT_TOKEN in .env

Problem: Want to add new admin
Fix:     Edit .env: ADMIN_IDS=ID1,ID2,ID3 (comma-separated, no spaces)
