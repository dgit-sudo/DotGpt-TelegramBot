## ⚡ 5-MINUTE DEPLOYMENT

### 1. Install Fly CLI
```bash
brew install flyctl  # Mac
# Or: curl -L https://fly.io/install.sh | sh  # Linux
```

### 2. Login
```bash
flyctl auth signup
```

### 3. Deploy
```bash
cd /workspaces/DotGpt-TelegramBot
flyctl launch
flyctl secrets set BOT_TOKEN="your_token_here"
flyctl deploy
```

### 4. Test
- Telegram → search your bot → /start → Done! ✅
